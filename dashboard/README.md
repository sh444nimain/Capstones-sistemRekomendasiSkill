# SkillMatch.AI Dashboard

Dashboard interaktif berbasis Streamlit untuk eksplorasi data lowongan kerja dan analisis kebutuhan skill industri.

## 📌 About Dashboard

SkillMatch.AI Dashboard membantu pengguna memahami tren kebutuhan skill dan kategori pekerjaan berdasarkan dataset lowongan kerja.

Dashboard ini menampilkan visualisasi data yang informatif dan interaktif untuk memberikan insight terkait:

- Kategori pekerjaan dengan demand tertinggi
- Distribusi jumlah skill pada lowongan kerja
- Skill yang paling banyak dibutuhkan pada bidang HR
- Skill yang paling banyak dibutuhkan pada bidang Information Technology

## ⚙️ Installation

Clone repository:

```bash
git clone https://github.com/sanhappyending/dashboardCapstone.git
```

Masuk ke folder project:

```bash
cd dashboardCapstone
```

Buat virtual environment:

```bash
python -m venv env
```

Aktifkan virtual environment:

### Windows

```bash
.\env\Scripts\activate
```

### Mac/Linux

```bash
source env/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run Dashboard

Jalankan dashboard menggunakan Streamlit:

```bash
python -m streamlit run app.py
```

## 📊 Dashboard Sections
